# Arena artwork

Three original images were created with the built-in image generation tool for this redesign. Production assets are WebP encodings; the generated PNG originals are retained in the local image-generation output folder.

- `arena-background.webp` (44,694 bytes): a dark futuristic chess arena with obsidian architecture, cyan/magenta edge lights, a distant chessboard floor, and open space behind the UI. Used for the page background.
- `arcade-button.webp` (63,964 bytes): a straight-on square smoked-navy enamel key with a machined bezel, cyan edge lights and a faint embossed knight. Used on the human time-control buttons; labels remain accessible HTML.
- `laser-duel.webp` (104,984 bytes): transparent artwork of an ivory knight and obsidian rook pointing cyan/magenta laser blasters at each other. The home footer animates their recoil, projectiles and impact locally in CSS. Pause and reduced-motion support are provided by `LaserDuel.tsx`.

No generated text is embedded in the controls. Existing generated boss portraits, board/piece themes and audio remain in their existing asset inventories.
