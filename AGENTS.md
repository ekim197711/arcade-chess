# Page layout

- Aim to make every page fully viewable within one screen without horizontal or vertical scrolling. Scrolling is acceptable for genuinely large pages, but first make good use of the available screen width.
- Use left and right side panels for buttons, controls, and extra metadata, following the layout of the historical game replay page. Keep primary game content in the center.
- Place the name and a link to the source in the right panel when that information is available.
- Make chessboards as large as the available screen space allows, while keeping the complete board and surrounding controls visible without scrolling. Limit board size by both available width and available viewport height; never let the board grow beyond that space.
- Check layouts at desktop, shorter laptop, and mobile viewport sizes. Adapt panel spacing and board size to fit each screen.
