# Additional chess piece sets

Three original sculptural sets were generated with the built-in `image_gen` tool:

- **Kintsugi 3D:** ivory and charcoal porcelain repaired with fine gold seams.
- **Aurora Glass 3D:** opalescent pale glass and deep indigo glass with flowing ribbons.
- **Verdigris 3D:** limestone and aged green bronze with botanical reliefs.

The complete production prompts are in [ai-prompts.json](ai-prompts.json). Original
transparent 3 × 4 atlases are preserved in `sources/`, outside the web assets.
Each atlas contains white king, queen, bishop, knight, rook, pawn, then the same
six black pieces, in row-major order.

**Tournament 2D** is original geometric Staunton vector artwork. **Woodcut 2D**
uses angular bookplate silhouettes and fine hatching. Their editable SVG sources
are in `sources/tournament-2d/` and `sources/woodcut-2d/`; these two flat sets are
drawn in code rather than AI generated.

All five sets export twelve transparent PNGs at both 256 and 512 pixels into
`public/pieces/<set>/<size>/`. Runtime uses the existing 256-pixel sprite loader.
Sprites have a consistent centered canvas and baseline; relative piece sizes
remain controlled by `PieceArtwork`.

To reproduce the exports without adding a runtime dependency:

```powershell
npm install --prefix .tmp/piece-tools --no-audit --no-fund sharp
node scripts/prepare-piece-sets.mjs
```

The export script crops the atlas cells, removes faint extraction halos without
adding a background, and retains smooth alpha edges. AI artwork itself is never
regenerated by the export script.
